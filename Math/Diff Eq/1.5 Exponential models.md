A type of separable equation
![](Pasted%20image%2020261105070927.png)

How do we wind up with $P=P_0e^{rt}$?

Well, we start with this simple diff eq:
$\dfrac{dP}{dt}=KP$

| $\dfrac{dP}{dt}$ | Change in population over time                         |
| ---------------- | ------------------------------------------------------ |
| K                | some constant                                          |
| P                | population                                             |
|                  | Aka, the bigger the population, the bigger the growth. |

| STEP 1 SEPERATE        |                                                                   |
| ---------------------- | ----------------------------------------------------------------- |
| $\dfrac{dP}{dt}=KP$    | Starting diff eq                                                  |
| $dP*\dfrac{1}{P}=K*dt$ | Separate the P's and the T's<br>P's on the left, T's on the right |

| STEP 2 INTEGRATE                 |                                                                                                                                                                             |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| $\int dP*\dfrac{1}{P}=\int K*dt$ | Integrate both sides                                                                                                                                                        |
| $ln\|P\|=K*t+C$                  | Rule: $\int \dfrac{1}{x}=ln\|x\|$<br>(It should be ln\|x\| not ln\|\|x\|\| idk why its doing that)<br>The power rule does not apply to $\dfrac{1}{x}$, hence the rule above |
| $e^{ln\|P\|}=e^{K*t+C}$          | Rule: $e^{ln(x)}=x$                                                                                                                                                         |
| $\|P\|=e^{K*t+C}$                |                                                                                                                                                                             |
| $\|P\|=e^{K*t}*e^C$              | Rule: $e^{a+b}=e^a*e^b$                                                                                                                                                     |
| $\|P\|=Ce^{Kt}$                  | $e^C$ is just another arbitrary constant C                                                                                                                                  |
| $P=Ce^{Kt}$                      | If we assume that P (population) is positive                                                                                                                                |
$P=Ce^{Kt}$

### Example 1

| Parts of the puzzle |                            |
| ------------------- | -------------------------- |
| Diff eq             | $\dfrac{dy}{dt}=3y$        |
| Initial Condition   | $y(0)=2$ <br>When t=0, y=2 |
| Unknown             | When y=4, t=?              |

| STEP 1 SEPERATE                  | Description                                                                                                                     |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| $\dfrac{dy}{dt}=3y$              | Take diff eq                                                                                                                    |
| $dy*\dfrac{1}{y}=3*dt$           | Get $t\ and\ dt$ on one side, $y\ and\ dy$ on the other<br>                                                                     |
|                                  | $\dfrac{1}{y}$ is easier to integrate than $\dfrac{1}{3y}$ heads up                                                             |

| STEP 2 INTEGRATE                 |                                                                                                                                 |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| $\int dy*\dfrac{1}{y}=\int 3*dt$ | Integrate both sides                                                                                                            |
| $\ln\left\| y \right\| = 3t + C$ | Don't forget this integration rule:<br>$\int \dfrac{1}{y}dy=ln\left\|y\right\|$                                                 |
| $e^{ln\|y\|}=e^{3t+C}$           |                                                                                                                                 |
| $\|y\|=e^{3t+C}$                 | e/natural log rule: $e^{ln\|y\|}=\|y\|$                                                                                         |
| $\|y\|=e^{3t}*e^{C}$             | Exponent addition rule: $e^{a+b}=e^a*e^b$                                                                                       |
| $\|y\|=Ce^{3t}$                  | $e^C=C_2$<br>You can just write $C_2$ as $C$ though<br>$C_2$ is a different arbitrary constant, but still an arbitrary constant |

| STEP 3 Solve for C / Get y Equation for Initial Condition |                                        |
| --------------------------------------------------------- | -------------------------------------- |
| $\|y\|=Ce^{3t}$                                           |                                        |
| $2=Ce^{3*0}$                                              | Plug in initial condition              |
| $2=C$                                                     | $e^{0}$ is just 1                      |
| $\|y\|=2e^{3t}$                                           | Now we have the equation for t=0, y=2! |
