### What is a Solution to a Diff Eq?
The solution to an algebraic equation:
- a number
- a set of numbers

x + 5 = 7
x = 2

The solution to a Differential Equation:
- an equation
- a set of equations

Example stolen from Kahn Academy:

$y'=xy^2$
Is $y=\dfrac{2}{9+x^2}$ a solution to the above equation?

- Use the bottom equation to turn the top equation into all x
- After the top equation is all x, check if it is legit
- If not legit, you know the bottom equation is not a solution

$y=\dfrac{2}{9+x^2}$

Get the derivative:
$y'=\dfrac{-4x}{(9+x^2)^2}$

Now that you have $y$ and $y'$, substitute and turn top equation into all x:
$y'=xy^2$ 

$\dfrac{-4x}{(9+x^2)^2}=x*(\dfrac{2}{9+x^2})^2$

$\dfrac{-4x}{(9+x^2)^2}\neq\dfrac{4x}{(9+x^2)^2}$



### K - constant of proportionality
When things are proportionally related to each other, either directly or inversely.

Converse or Direct relationship:
$y = k * x$
$number\_of\_inches = 12 * number\_of\_feet$
K is 12

Inverse or Indirect relationship:
$y=\dfrac{k}{x}$
$frequency\_in\_hz = \dfrac{1000}{number\_of\_milliseconds}$
K is 1000

## Linear Solution to Diff Eq

$y'=-2x+3y-5$

Find solution that is a linear equation aka $y=mx+b$

Same idea:
- Use $y=mx+b$ to make top equation all x's

$y=mx+b$
$y'=m$

Aaaaand substitute:
$m=-2x+3(mx+b)-5$

**Needs to be true for ALL x's**
- Does it work out to x=x? Solution!
- Does it work out to x=2? Not a solution!

- Get rid of x
