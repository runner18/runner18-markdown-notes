### What is a Solution to a Diff Eq?
The solution to an algebraic equation:
- a number
- a set of numbers

x + 5 = 7
x = 2

The solution to a Differential Equation:
- an equation
- a set of equations

Example stolen from Kahn Academy:

$y'=xy^2$
Is $y=\dfrac{2}{9+x^2}$ a solution to the above equation?

- Use the bottom equation to turn the top equation into all x
- After the top equation is all x, check if it is legit (works out to 1=1 or TRUE)
- If not legit, you know the bottom equation is not a solution


$y=\dfrac{2}{9+x^2}$

Get the derivative:
$y'=\dfrac{-4x}{(9+x^2)^2}$

Now that you have $y$ and $y'$, substitute and turn top equation into all x:
$y'=xy^2$ 

$\dfrac{-4x}{(9+x^2)^2}=x*(\dfrac{2}{9+x^2})^2$

$\dfrac{-4x}{(9+x^2)^2}\neq\dfrac{4x}{(9+x^2)^2}$



### K - constant of proportionality
When things are proportionally related to each other, either directly or inversely.

Converse or Direct relationship:
$y = k * x$
$number\_of\_inches = 12 * number\_of\_feet$
K is 12

Inverse or Indirect relationship:
$y=\dfrac{k}{x}$
$frequency\_in\_hz = \dfrac{1000}{number\_of\_milliseconds}$
K is 1000

## Linear Solution to Diff Eq
Example:
$y'=-2x+3y-5$

Find solution that is a linear equation aka $y=mx+b$

Same idea:
- Use $y=mx+b$ to make top equation all x's
- Then solve all x's equation to see if legit solution (works out to 1=1 or TRUE)
- "Needs to be true for all x's"



$y=mx+b$ 
$y'=m$
$m=-2x+3(mx+b)-5$  <--- aaaaand substitute

To get a solution, remove all the x's!!! 
Why? Solution should be true no matter what x is! x should not matter! Get rid of x!

$m=-2x+3mx+3b-5$
$m=x(-2+3m)+3b-5$

If $x(-2+3m)$ becomes $x(0)$, $x$ can be eliminated!
$-2+3m=0$
$m=\frac23$

If $m=\frac{2}{3}$
$\frac23=x(0)+3b-5$
$\frac23=3b-5$
Viola! No more x's!!!
See how much easier this is to solve after we got rid of x?
Friggin' sweet!

Now get it to $\frac23=\frac23$ aka $1=1$ (because that's a legit solution, it's literally just TRUE)
$\frac23=3b-5$
$5\frac23=3b$
$b=1\frac89$

And double checking to see if that is true...
$\frac23=3b-5$
$\frac23=3(1\frac89)-5$
$\frac23=\frac23$ aka $1=1$ aka TRUE

Solution is
$y=\frac23x+1\frac89$


## Check if Solution to Diff Eq
Is equation a **solution** to a diff eq? Follow these steps to find out:
1. **PREP STEP:** What is $y$ and $y'$ of equation?
2. **SUBSTITUTE STEP:** Substitute *y* and *y'* of equation into diff eq
3. **VERIFY STEP:** Does it work out to 1=1? If yes, equation is the solution!

$x^2y'+e^{-y}=0$
