### What is a Solution to a Diff Eq?
The solution to an algebraic equation:
- a number
- a set of numbers

x + 5 = 7
x = 2

The solution to a Differential Equation:
- an equation
- a set of equations

Example stolen from Kahn Academy:

$y'=xy^2$
Is $y=\dfrac{2}{9+x^2}$ a solution to the above equation?

- Use the bottom equation to turn the top equation into all x
- After the top equation is all x, check if it is legit (works out to 1=1 or TRUE)
- If not legit, you know the bottom equation is not a solution


$y=\dfrac{2}{9+x^2}$

Get the derivative:
$y'=\dfrac{-4x}{(9+x^2)^2}$

Now that you have $y$ and $y'$, substitute and turn top equation into all x:
$y'=xy^2$ 

$\dfrac{-4x}{(9+x^2)^2}=x*(\dfrac{2}{9+x^2})^2$

$\dfrac{-4x}{(9+x^2)^2}\neq\dfrac{4x}{(9+x^2)^2}$



### K - constant of proportionality
When things are proportionally related to each other, either directly or inversely.

Converse or Direct relationship:
$y = k * x$
$number\_of\_inches = 12 * number\_of\_feet$
K is 12

Inverse or Indirect relationship:
$y=\dfrac{k}{x}$
$frequency\_in\_hz = \dfrac{1000}{number\_of\_milliseconds}$
K is 1000

## Linear Solution to Diff Eq
Example:
$y'=-2x+3y-5$

Find solution that is a linear equation aka $y=mx+b$

Same idea:
- Use $y=mx+b$ to make top equation all x's
- Then solve all x's equation to see if legit solution (works out to 1=1 or TRUE)
- "Needs to be true for all x's"



$y=mx+b$ 
$y'=m$
$m=-2x+3(mx+b)-5$  <--- aaaaand substitute

To get a solution, remove all the x's!!! 
Why? Solution should be true no matter what x is! x should not matter! Get rid of x!

$m=-2x+3mx+3b-5$
$m=x(-2+3m)+3b-5$

If $x(-2+3m)$ becomes $x(0)$, $x$ can be eliminated!
$-2+3m=0$
$m=\frac23$

If $m=\frac{2}{3}$
$\frac23=x(0)+3b-5$
$\frac23=3b-5$
Viola! No more x's!!!
See how much easier this is to solve after we got rid of x?
Friggin' sweet!

Now get it to $\frac23=\frac23$ aka $1=1$ (because that's a legit solution, it's literally just TRUE)
$\frac23=3b-5$
$5\frac23=3b$
$b=1\frac89$

And double checking to see if that is true...
$\frac23=3b-5$
$\frac23=3(1\frac89)-5$
$\frac23=\frac23$ aka $1=1$ aka TRUE

Solution is
$y=\frac23x+1\frac89$


## Check if Solution to Diff Eq
Is equation a **solution** to a diff eq? Follow these steps to find out:
1. **PREP STEP:** What is $y$ and $y'$ of equation?
2. **SUBSTITUTE STEP:** Substitute *y* and *y'* of equation into diff eq
3. **VERIFY STEP:** Does it work out to 1=1? If yes, equation is the solution!

### Example
Differential equation:
$x^2y'+e^{-y}=0$

Which equation is solution for all values of C?
A) $y=ln(\frac1x)+C$
B) $y=ln(\frac1x+C)$

| A) PREP STEP            | What is $y$ and $y'$ of equation? |
| ----------------------- | --------------------------------- |
| $y=ln(\frac1x)+C$       | take equation                     |
| $y'=\dfrac{1}{\frac1x}$ | derive                            |
| $y'=x$                  | now you know y and $y'$           |

| A) SUBSTITUTE STEP                   | Substitute $y$ and $y'$ of equation into diff eq |
| ------------------------------------ | ------------------------------------------------ |
| $x^2y'+e^{-y}=0$                     | take diff eq                                     |
| $x^2(x)+e^{-(ln(\frac1x)+C)}=0$      | substitute $y'$ and $y''$                        |
| $x^3+\dfrac{1}{e^{ln(\frac1x)+C}}=0$ |                                                  |
| $x^3+\dfrac{1}{\frac1x*e^C}=0$       | $e^{ln(x)}=e$ rule                               |
| $x^3+\dfrac{1}{\frac{e^{C}}{x}}=0$   |                                                  |
| $x^3+\dfrac{x}{e^C}=0$               |                                                  |

| A) VERIFY STEP         | Does it work out to 1=1? If yes, equation is the solution! |
| ---------------------- | ---------------------------------------------------------- |
| $x^3+\dfrac{x}{e^C}=0$ | Is this the solution? ... probably not                     |

| B) PREP STEP                              | What is $y$ and $y'$ of equation? |
| ----------------------------------------- | --------------------------------- |
| $y=ln(\dfrac1x+C$)                        | take equation                     |
| $y'=\dfrac{1}{\frac1x+C}*(-x^{-2})$       | derive                            |
| $y'=\dfrac{1}{\frac1x+C}*-\dfrac{1}{x^2}$ | simplify                          |
| $y'=-\dfrac{1}{(\frac1x+C)x^2}$           | now you know y and y'             |

| B) SUBSTITUTE STEP                                       | Substitute $y$ and $y'$ of equation into diff eq |
| -------------------------------------------------------- | ------------------------------------------------ |
| $x^2y'+e^{-y}=0$                                         | take diff eq                                     |
| $x^2(-\dfrac{1}{(\frac1x+C)x^2})+e^{-(ln(\frac1x+C))}$=0 | substitute y and y'                              |
| $-\dfrac{1}{\frac1x+C}+\dfrac{1}{e^{ln(\frac1x+C)}}=0$   |                                                  |
| $-\dfrac{1}{\frac1x+C}+\dfrac{1}{\frac1x+C}=0$           |                                                  |
| $\dfrac{1}{\frac1x+C}-\dfrac{1}{\frac1x+C}=0$            |                                                  |
| 0=0                                                      |                                                  |

| B) VERIFY STEP | Does it work out to 1=1? If yes, equation is the solution! |
| -------------- | ---------------------------------------------------------- |
| 0=0            | Is this the solution? ... yep! 0=0 is 1=1 or TRUE          |

### Example 2
There are two values of $a$ that make $y=e^{ax}$ a solution of the following diff. eq.:
$y''-7y''+12y=0$

What is the sum of these two values?

| PREP STEP       | What is y and y' (and y'') of equation?   |
| --------------- | ----------------------------------------- |
| $y=e^{ax}$      | take equation                             |
| $y'=ae^{ax}$    | derive                                    |
| $y''=a^2e^{ax}$ | derive again! now you know y, y', and y'' |

| SUBSTITUTE STEP                         | Substitute y and y' (and y'') into diff eq |
| --------------------------------------- | ------------------------------------------ |
| $y''-7y'+12y=0$                         | take diff eq                               |
| $(a^2e^{ax})-7(ae^{ax})+12({e^{ax}})=0$ | subsitute y and y' and y''                 |
| $e^{ax}(a^2-7a+12)=0$                   | factor out $e^{ax}$                        |
| $a^2-7a+12$                             | oh look! it's a quadratic equation!        |
| $a^2-7a+12=(a-4)(a-3)$                  | -4 and -3 multiply to 12 and add to -7     |
| $e^{ax}(a-4)(a-3)=0$                    |                                            |

| VERIFY STEP          | "There are two values of $a$ that make \[equation] a solution..."              |
| -------------------- | ------------------------------------------------------------------------------ |
| $e^{ax}(a-4)(a-3)=0$ | What values of $a$ turn this into 0=0? Answer: a=3 and a=4                     |
| $e^{ax}(a-4)(a-3)=0$ | Here's a demonstration for a=4. a=3 would work the same                        |
| $e^{ax}(4-4)(4-3)=0$ |                                                                                |
| $e^{ax}(0)(1)=0$     | $e^{ax}(0)(1)$ just multiplies to zero lol                                     |
| $0=0$                | solution!                                                                      |
|                      | "What is the sum of these two values?" <br>7, because 3+4=7. Final answer is 7 |
### Example 3
An unknown function $f$ solves the diff eq: $f'(x)=2f(x)+x$
Satisfies $f(1)=-2$ 

What is $f'(1)$ and $f''(1)$? What does curve look like at $f(1)$?

| Solve for $f(1)$ |                                           |
| ---------------- | ----------------------------------------- |
| $f'(x)=2f(x)+x$  | Take diff eq                              |
| $f'(1)=2f(1)+1$  | $f(1)$ means x=1, so replace x's with 1's |
| $f'(1)=2*-2+1$   | Remember, $f(1)=-2$                       |
| $f'(1)=-4+1$     |                                           |
| $f'(1)=-3$       | now you know $f'(1)$                      |
Boy I hope this still makes sense when I come back to it

| Solve for $f''(1)$ |                                            |
| ------------------ | ------------------------------------------ |
| $f'(x)=2f(x)+x$    | Take diff eq                               |
| $f''(x)=2f'(x)+1$  | derive it - now you can solve for $f''(x)$ |
| $f''(1)=2f'(1)+1$  |                                            |
| $f''(1)=2*(-3)+1$  | substitute $f'(1)$ for $-3$                |
| $f''(1)=7$         | now you know $f''(1)$                      |
At x=1, slope is negative ($f'(1)=-3$) but the slope is in the process of increasing ($f''(1)=7$)
