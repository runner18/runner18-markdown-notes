Slope fields are a way to visualize what a diff eq would look like.

### Example 1
What differential equation generates the slope field?
![]({EB9923D4-B946-4F72-8900-6F048A553CA2}.png)


A) $\frac{dy}{dx}=x+y$

B) $\frac{dy}{dx}=x-y$

C) $\frac{dy}{dx}=y-x$

D) $\frac{dy}{dx}=\dfrac{x}{y}$

E) $\frac{dy}{dx}=-\dfrac{x}{y}$


Take a point like x=1 y=1. 
If the slope on the graph is different than the slope for a differential equation, we can eliminate that diff eq!

| x   | y   | Slope on Graph (just eye it) | $\frac{dy}{dx}$ for A | $\frac{dy}{dx}$ for B | $\frac{dy}{dx}$ for C | $\frac{dy}{dx}$ for D | $\frac{dy}{dx}$ for E |
| --- | --- | ---------------------------- | --------------------- | --------------------- | --------------------- | --------------------- | --------------------- |
| 1   | 1   | 0                            | 2                     | 0                     | 0                     | 1                     | -1                    |
| -1  | -1  | 0                            | -2                    | 0                     | 0                     | 1                     | -1                    |
| 1   | -1  | positive                     | 0                     | 2                     | -2                    | -1                    | 1                     |
| 3   | 2   | positive (probably 1)        | 5                     | 1                     | -1                    | 3/2                   | -3/2                  |
Equation B is the only one that always matches the graph, in terms of slope.

### Example #2
What is the general solution to the differential equation that generated the slope field?
![]({9FC84B8E-96A8-4842-AD4F-9F44CAE60207}.png)

A) $y=-ln(x)+C$

B) $x=\sqrt{y}+C$

C) $x=-\sqrt{y}+C$

D) $y=\sqrt{x}+C$

E) $y=-\sqrt{x}+C$


|     | Kahn Academy's method                                                                                                                                                 |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1/2 | Pick any segment on the slope field and, using the direction of the segment, draw a particular solution to the differential equation used to create this slope field. |
| 2/2 | This should give you a shape resembling half of a sideways parabola. Hence $y=\sqrt{x}+C$ is the requested general solution                                           |
In other words, do this:
![](Pasted%20image%2020261005190547.png)

| x   | y   |
| --- | --- |
| 0   | 0   |
| 1   | 1   |
| 4   | 2   |
| 9   | 3   |
| 16  | 4   |


| How I did it               |                                                                                                                                                                           |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|                            | The entire left half of the graph is missing!                                                                                                                             |
|                            | The equation might have $\sqrt{x}$, since you can never square root a negative number and x is never negative on the graph.<br>With this in mind let's try $y=\sqrt{x}+C$ |
| $y=\sqrt{x}+C$             | Derive $y=\sqrt{x}+C$ so you can compare equation slopes with graph slopes                                                                                                |
| $y=x^{1/2}+C$              | $\sqrt{x}=x^{1/2}$                                                                                                                                                        |
| $y'=\dfrac{1}{2}x^{-1/2}$  | Now derive                                                                                                                                                                |
| $y'=\dfrac{1}{2*\sqrt{x}}$ | Simplify.<br>Now you can see what the equation says the slope is vs the graph.                                                                                            |
| $y'=1/2$                   | Check (1,1). Equation says slope is 1/2. This matches up with the graph.                                                                                                  |
|                            | Other points match up as well. It's probably answer D.                                                                                                                    |
### Example #3
If the initial condition is $(0,0)$, what is the range of the solution curve $y=f(x)$ for $x\geq0$?


![]({FB506BF3-3EE7-40E5-9D25-9C5788E95239}.png)

Red x because $x\geq0$

### Example #4
What is the general solution to the differential equation that generated the slope field?
![]({95152B2F-C856-443E-BD4E-CAEC1BFA0FC2}.png)

A) $x=cos(y)+C$
B) $y=-cos(x)+C$
C) $y=cos(x)+C$
D) $y=-sin(x)+C$

Slope depends on x, so probably answers B-D

| Original equation | Derivative   |
| ----------------- | ------------ |
| B) $y=-cos(x)+C$  | $y'=sin(x)$  |
| C) $y=cos(x)+C$   | $y'=-sin(x)$ |
| D) $-sin(x)+C$    | $y'=-cos(x)$ |
Now we know slopes for each equation, and compare against slopes on graph.
