Is this diff eq equation separable?
Can you get x's and dx on one side, and y's and dy's on the other side?

Example:
Is $xy'+y=3$ separable?

| Equation              | Description                 |
| --------------------- | --------------------------- |
| $xy'+y=3$             |                             |
| $x\dfrac{dx}{dy}=3-y$ |                             |
| $x{dx}=(3-y)dy$       | yes, x's and dx on one side |
