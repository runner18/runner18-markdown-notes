Say you have

| Parts of the puzzle                     |                    |
| --------------------------------------- | ------------------ |
| Diff eq is                              | $\dfrac{dy}{dx}=y$ |
| A solution to the diff eq               | ???                |
| One of the solution's coordinate points | (0,1) or y(0)=1    |
To graph this solution to the diff eq, you would need to constantly update $\frac{dy}{dx}$ and $y$ to be equal to each other as x changes.

A computer could give pretty accurate answer by checking and updating $\frac{dy}{dx}$ and $y$ for every tiny change in x. 

Us lowly humans can get a rough estimate by only updating on x=1, x=2, x=3, etc.

| x   | y<br>add last $\frac{dy}{dx}$<br>(e.g. $\frac{dy}{dx}=2$ and $\frac{change\ in\ y}{change\ in\ x}=\frac{???}{1}$, meaning $change\ in\ y$ is $2$ or $\frac{dy}{dx}$)<br> | $\dfrac{dy}{dx}$<br>set to (see diff eq for instructions, in this case $\frac{dy}{dx}=y$) |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| 0   | **1**                                                                                                                                                                    | 1                                                                                         |
| 1   | **2** = 1 + 1                                                                                                                                                            | 2                                                                                         |
| 2   | **4** = 2 + 2                                                                                                                                                            | 4                                                                                         |
| 3   | **8** = 4 + 4                                                                                                                                                            | 8                                                                                         |

### Example 1
Consider the differential equation $\frac{dx}{dy}=3x-2y$

Let $g=g(x)$ be a solution to the differential equation with the initial condition g(0)=k where k is a constant. Euler's method, starting at $x=0$ with a step size of 1 gives the approximation of $g(2)\approx4.5$

Find the value of k.


| Parts of the puzzle                                     |                                             |
| ------------------------------------------------------- | ------------------------------------------- |
| Diff eq                                                 | $\frac{dx}{dy}=3x-2y$                       |
| One of the solutions to the diff eq                     | $g=g(x)$                                    |
| The starting point: one of the points on the solution   | $g(0)=k$ aka $x=0, y=k$                     |
| An estimated point of the solution using Euler's method | $g(2)\approx4.5$ aka when $x=2,y\approx4.5$ |
Basically, do Euler's method but with k since we don't know k yet.

| x<br>add 1 | y<br>add last $\frac{dy}{dx}$ | $\frac{dy}{dx}$<br>set to 3x-2y |
| ---------- | ----------------------------- | ------------------------------- |
| 0          | k                             | $3*0-2*k=-2k$                   |
| 1          | $k+(-2k)=-k$                  | $3*1-2*-k=3+2k$                 |
| 2          | $k+(3+2k)=3+k$                |                                 |
Now we know g(2) is in terms of K.

|                            |                                                  |
| -------------------------- | ------------------------------------------------ |
| $g(2)\approx4.5, g(2)=3+k$ | Now we know g(2) in terms of K                   |
| $4.5=3+k$                  | Set g(2) in terms of K to 4.5, since g(2) is 4.5 |
| $1.5=k$                    | k is 1.5                                         |


The approximation of g(2) is 4.5, and g(2) in this table is 3+k
$g(2)\approx4.5=3+k$
$k=1.5$
